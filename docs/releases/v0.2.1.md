# Aries Image Studio 0.2.1

A polish release: it fixes the known issues listed for
[0.2.0](v0.2.0.md) and makes prompt enhancement easier to follow.

## Prompt enhancement

- **Longer limit.** The enhancer may now generate up to 2048 tokens (was 1536). Many
  runs used to stop at the old limit. A run that reaches the limit still counts as
  complete and keeps its prompt: by then the description is already detailed.
- **Real progress.** The tile's bar now follows the tokens generated, aiming at 85 % of
  the limit, where most runs end, and shows the time left from the live speed. A run
  that goes past it shows an indeterminate bar and "almost done…".

## Fixes for the 0.2.0 known issues

- **No more frozen 0 %.** Reading prompt and Finishing show an indeterminate bar while
  the encoder and decoder work (they report no steps).
- **Honest times.** The timeline and gallery show generation time: the sum of the
  stage times, enhance included, without queue wait. The Inspector shows the total
  time and a breakdown: each stage (enhance with tokens and tok/s, denoise with
  steps × s/step, decode with its mode), generation time, queue & model loading, and
  the total. Images made before 0.2.0 now show their generation time instead of N/A.
- **Read from the job.** The Inspector's pipeline details show the job's stages, decode
  mode, the GPU that decoded it and its peak VRAM instead of fixed hardware text.
- **Status panel.** A card's peak VRAM covers its current or last worker run, and the
  host RAM spill warning appears only above 1 GB; the driver keeps a small baseline
  there.

## Upgrading

Pull and rebuild both the backend container and the web app: the token limit and the
peak VRAM reset are backend changes. Existing history in the browser is kept.

Still true from 0.2.0: no authentication (keep it on a trusted network), and history
lives in the browser.

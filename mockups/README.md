# Mockups

Design mockups (Stitch export: screens as PNG plus the HTML/CSS it produced).

These are the **visual reference** for `web/`: layout, color, type, spacing.
`docs/SPEC_UI.md` is the reference for **behavior** — states, interactions,
keyboard, accessibility. Where a mockup and SPEC_UI.md disagree on behavior,
SPEC_UI.md wins.

Light theme is the default; dark must be equally polished.
